Kỹ Năng, Kiến Trúc & Quản Trị Hệ Thống

Tổng hợp toàn bộ các kỹ năng cốt lõi, kiến trúc phần mềm, thuật toán thực chiến, quản trị cơ sở dữ liệu và kinh nghiệm áp dụng AI trong quy trình lập trình của tôi.

Các Kỹ Năng Của Tôi

  • Ngôn ngữ lập trình: C# (.NET Framework & .NET 8), SQL, JavaScript / TypeScript, Java.
  • Backend Frameworks: ASP.NET Core Web API, ASP.NET MVC, Entity Framework Core, Entity Framework.
  • Frontend & Mobile: React 18, React Native, Tailwind CSS, Bootstrap 5, Razor View Engine.
  • Desktop Development: WPF với XAML, Windows Forms.
  • Công cụ & Môi trường: Visual Studio 2022, Git & GitHub, Docker, Postman, SSMS, IIS Express, Azure Cloud.

Các Kiến Trúc Tôi Được Học

  • Clean Architecture (Onion / Hexagonal): Phân tầng nghiêm ngặt Domain, Application (CQRS & MediatR), Infrastructure và Web API.
  • Thin Controller / Fat Service: Triệt tiêu monolithic fat controller; đóng gói 100% Business Logic vào Service Layer qua Interface và Dependency Injection.
  • Modular Monolith: Phân chia các Area / Module nghiệp vụ độc lập, đảm bảo tính đóng gói cao và dễ dàng tách Microservices khi mở rộng.
  • Offline-First Architecture: Thiết kế kiến trúc ngoại tuyến với SQLite cục bộ & AutoSync Engine ngầm đồng bộ hai chiều (Outbox Batch Push & Sequence Delta Pull).
  • Mô hình MVVM & MVC: Áp dụng chuẩn mực MVVM cho Desktop WPF và MVC cho Web ứng dụng.

Các Kỹ Năng Tôi Nắm Vững

  • Chuẩn mực OOP & SOLID: Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, Dependency Inversion.
  • Lập trình bất đồng bộ: Nắm vững `async/await`, giải phóng luồng máy chủ, chạy tác vụ nền ngầm với `Task.Run` và `BackgroundServices`.
  • Tích hợp Webhook & Cổng thanh toán: Lắng nghe và xử lý biến động số dư VietQR SePay, gạch nợ tự động 2-3s kèm Fallback API Polling.
  • Bảo mật & Phân quyền: JWT Bearer Authentication, Refresh Token, Role-Based Access Control (RBAC), ASP.NET Identity 2.0, OWIN.
  • Xử lý ngoại lệ & Kiểm thử: Global Exception Middleware, Viết Unit Test tự động với xUnit, Test Coverage cao.

Quản Trị Hệ CSDL

  • Microsoft SQL Server (SSMS): Thiết kế mô hình CSDL quan hệ chuẩn hóa (1NF, 2NF, 3NF), Stored Procedures, Triggers, Views, Foreign Keys.
  • Tối ưu hóa Index & Truy vấn: Clustered/Non-clustered Indexing, phân tích Execution Plan, triệt tiêu lỗi N+1 Query trong ORM.
  • SQLite & Embedded Database: Quản trị CSDL nhúng cục bộ trên Mobile (Expo) và Desktop (WPF), tích hợp mã hóa an ninh SQLCipher AES-256.
  • Entity Framework & LINQ: Thành thạo cả Code First (Migrations) và Database First (`.edmx`), tối ưu hóa LINQ với `AsNoTracking` và DTO Projection.

Kinh Nghiệm Sử Dụng AI Trong Lập Trình

  • Tích hợp Google Gemini Pro API & RAG Engine: Xây dựng module tự động bóc tách tài liệu bài giảng (.docx qua Mammoth XML, .pdf, .txt) và trợ lý hỏi đáp thông minh theo ngữ cảnh tài liệu.
  • Trợ lý AI Pair-Programming: Sử dụng các công cụ AI hiện đại (Antigravity, GitHub Copilot,Claude) để hỗ trợ rà soát lỗi logic, tối ưu hóa code và tăng tốc phát triển.
  • Sinh dữ liệu kiểm thử & Unit Tests tự động: Ứng dụng AI sinh mock data phong phú và các ca kiểm thử biên (edge cases) cho xUnit.
  • Thẩm định kiến trúc & Security: Sử dụng AI làm công cụ review độc lập nhằm kiểm tra sự tuân thủ nguyên lý SOLID và phát hiện lỗ hổng bảo mật.
